# indexregex

Index CSV/TSV regex tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/indexregex/

## Install / run

```bash
git clone https://github.com/theworker02/indexregex.git
cd indexregex
node src/cli.js
node --test
```
